# Ultimate AI & Data Science Interview Questions

A comprehensive interview preparation resource covering SQL, Python, Machine Learning, Deep Learning, Natural Language Processing (NLP), Generative AI and Agentic AI.

This repository provides subject-wise interview question collections in PDF format to help students, freshers and aspiring AI and Data Science professionals prepare for technical interviews.

**Topics include:** SQL fundamentals, queries, filtering, joins, aggregation, subqueries and other database concepts.

## How to Use This Repository

1. Choose the subject relevant to your interview preparation.
2. Open the corresponding PDF.
3. Attempt each question before checking your notes or other learning resources.
4. Practise coding questions independently wherever applicable.
5. Review difficult concepts and repeat the questions before your interview.
